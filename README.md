# Angry Judge: The Short Rant Contest

Write a short, funny rant about an everyday annoyance and let a furious judge decide which one lands hardest.

This entry rants about the office microwave: it beeps once when it finishes, then again every thirty seconds until you open the door and confess that reheating fish at work was a mistake. The program (`main.py`, standard library only) writes the rant to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

The rant (213 characters, inside the 1–400 character gate) is written to `/output/entry.txt`.
